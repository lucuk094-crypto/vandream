## 🎯 Deploy Sekarang (3 Langkah)

### 1️⃣ Login Vercel
👉 https://vercel.com/login

### 2️⃣ Import Project
- Klik **"Add New Project"**
- Pilih repository: **`lucuk094-crypto/vandream`**
- Klik **"Import"**

### 3️⃣ Set Environment Variables
⚠️ **PENTING - WAJIB DIISI!**

```
NUNOMIX_BASE_URL = https://nunodrama.my.id/api/nunomix
NUNOMIX_TOKEN = <your-token-here>
SITE_URL = https://your-vercel-url.vercel.app
```

Lalu klik **"Deploy"** → Tunggu 2-5 menit → **DONE!** 🎉
